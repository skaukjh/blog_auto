# 네이버 블로그 순차입력기 (C)

완성된 블로그 글을 네이버 글쓰기 화면에 **사람이 타이핑하듯 한 글자씩** 넣는 윈도우 데스크톱
프로그램입니다. 저장소의 A(글 생성)·B(이웃 자동화)와 독립적인 세 번째 프로젝트입니다.

## 왜 별도 프로그램인가

순차 입력은 실제 크롬 창을 띄우고 4~6분간 돌아야 합니다. Vercel 서버리스에는 디스플레이가
없고 함수 실행 상한이 300초라 원리적으로 불가능합니다. 그래서 A(Vercel)에 넣지 않고
데스크톱 앱으로 분리했습니다.

## 실행

`네이버블로그순차입력기.exe` **파일 하나만** 있으면 됩니다. 더블클릭하면 실행되고, 설치
과정도, 옆에 딸린 폴더도 필요 없습니다. USB에 담아 다른 PC로 옮겨도 그대로 실행됩니다.

```
typing-app/dist-single/네이버블로그순차입력기.exe   (약 71MB, 단일 파일)
```

빌드는 두 가지가 있습니다.
- `npm run build` → **단일 exe** (`dist-single/`, 배포용. 실행 시 임시폴더에 자동 압축 해제)
- `npm run build:folder` → 폴더형 (`dist/`, 디버깅용. exe + 딸린 파일들)

**단, PC에 크롬이 설치돼 있어야 합니다.** Playwright가 자체 Chromium을 내려받지 않고 시스템에
설치된 크롬을 그대로 씁니다(`channel: 'chrome'`). 덕분에 exe에 300MB짜리 브라우저를 넣지
않아도 되고, 평소 쓰던 크롬이라 네이버 쪽에서도 덜 낯설게 봅니다. 크롬이 없는 PC라면
크롬만 먼저 설치하면 됩니다.

## 사용 순서

1. 네이버 아이디·비밀번호 입력 (저장하지 않습니다. 창을 닫으면 사라집니다)
2. **글쓰기 주소 입력 (선택)** — 아래 "글쓰기 주소" 참고
3. 제목과 본문 붙여넣기 — 빈 줄로 문단을 나눕니다
4. 입력 속도 선택 (느리게 / 보통 / 빠르게)
5. `순차 입력 시작`

## 글쓰기 주소

어느 블로그에 쓸지는 두 가지로 정합니다.

- **비워 두면** 위에 입력한 아이디로 `blog.naver.com/아이디/postwrite` 를 자동으로 엽니다.
  블로그가 하나뿐이면 이대로 두면 됩니다.
- **주소를 넣으면** 그 주소를 우선합니다. 블로그가 여러 개거나 아이디와 블로그 주소가
  다를 때 씁니다. 아래 형태를 모두 받아 글쓰기 화면으로 바꿔 엽니다.
  - 글쓰기 주소 그대로: `https://blog.naver.com/myblog/postwrite`
  - 블로그 홈 주소: `https://blog.naver.com/myblog`
  - 특정 글 주소: `https://blog.naver.com/myblog/223456789`
  - 모바일 주소: `https://m.blog.naver.com/myblog`

네이버가 아닌 주소를 넣으면 시작하지 않고 알려줍니다.

크롬 창이 뜨면 **건드리지 마세요.** 입력 중 마우스나 키보드를 쓰면 커서 위치가 어긋납니다.
2차 인증 화면이 뜨면 그때만 직접 처리하면 됩니다 (최대 2분 대기).

## 안전장치

- **자동 발행하지 않습니다.** 입력이 끝나면 크롬 창을 열어 둔 채 멈춥니다. 사진을 넣고
  검토한 뒤 직접 발행하세요
- `[IMAGE_N]` 마커는 기본적으로 그대로 입력됩니다. 사진 넣을 자리 표시로 쓰고 발행 전에
  지우세요. 체크박스로 제거하고 넣을 수도 있습니다
- 입력 도중 `중단` 버튼을 누르면 현재 문장까지만 마치고 멈춥니다
- 입력 중 창을 닫으려 하면 한 번 확인합니다

## 사람처럼 입력하는 방식

| 구간 | 간격 |
|---|---|
| 글자 사이 | 선택한 속도의 ±40% 범위에서 문장마다 다시 뽑음 |
| 긴 문장(25자 초과) 중간 | 0.15~0.5초 한 번 멈춤 |
| 문장 끝 | 0.25~0.9초 |
| 문단 사이 | 0.9~2.2초 |

## 개발

```bash
npm install
npm start          # 개발 모드로 실행
npm run build      # dist/ 에 배포용 폴더 생성
node test-chrome.cjs   # 크롬 실행·한글 입력만 점검 (네이버 계정 불필요)
```

## 알려진 제약

- **스마트에디터 ONE의 DOM 셀렉터는 네이버가 예고 없이 바꿉니다.** `lib/naver-typer.cjs`
  상단의 `TITLE_SELECTORS` / `BODY_SELECTORS` 에 다중 폴백을 두었지만, 어느 날 갑자기
  "입력 영역을 찾지 못했습니다"가 나오면 그 상수부터 확인하세요
- **실제 네이버 계정으로 끝까지 돌려본 적이 없습니다.** 크롬 실행과 한글 입력까지는
  검증됐지만(`test-chrome.cjs`), 로그인 이후 에디터 조작은 첫 실전 실행에서 조정이
  필요할 가능성이 높습니다
- 배포 폴더가 284MB입니다. 대부분 Electron 런타임이라 줄이기 어렵습니다
- 코드 서명을 하지 않아 처음 실행할 때 Windows SmartScreen 경고가 뜹니다.
  `추가 정보` → `실행`을 누르면 됩니다
